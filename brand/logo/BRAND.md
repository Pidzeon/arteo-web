# Arteo — Logo Guidelines

## 1. The logo
- **Idea**: the "a" and the "r" share one stroke. Where they meet, the two print inks overprint into a third colour. It brings the website's risograph idea into the logo itself.
- **Versions**
  - **Wordmark** `arteo` (primary). Use it wherever there is room.
  - **Symbol** `ar`, for square or tiny spaces: favicon, avatar, app icon, stamp.
  - **Small cut** `arteo-symbol-small*`, a heavier drawing for 32 px and below (favicon, tab icons).
- There is no symbol + wordmark lockup on purpose: the wordmark already contains the symbol.

The artwork is generated by `build_final.py`. Change the geometry there, not by hand in the SVGs.

## 3. Clear space
Keep empty space of **½ x-height** on every side. The x-height is the height of the "o". The space grows with the logo; never use a fixed distance.

## 4. Minimum size
| Version | Screen | Print |
|---|---|---|
| Wordmark | 72 px wide | 18 mm wide |
| Symbol | 24 px (32 px and below: small cut) | 6 mm (below that: small cut) |

## 5. Colour
| Name | HEX | RGB | CMYK (approx.) | Riso / spot |
|---|---|---|---|---|
| Blue (ink 1) | `#2A4BD7` | 42 75 215 | 85 70 0 0 | Riso Blue / ~Pantone 2728 C |
| Fluo pink (ink 2) | `#FF4AA5` | 255 74 165 | 0 80 0 0 | Riso Fluorescent Pink / ~Pantone 806 C |
| Overprint | `#2A168B` | 42 22 139 | (comes from the two inks) | not a separate ink |
| Ink black | `#18181C` | 24 24 28 | 0 0 0 100 | — |
| Paper | `#EEEEE9` | 238 238 233 | — | — |
| Dark mode | blue `#5672FF`, pink `#FF5DB1`, overprint `#FFA5FF`, text `#ECECE6` on `#141417` | | | |

- **Print**: in two-colour print (riso, screen print), print the overprint area with both inks on top of each other. In CMYK it is a separate colour; check it on a proof. The CMYK and Pantone values are approximations, so confirm them with the printer.
- **Approved pairs**: colour on paper/white · colour-dark on `#141417`/black · white on blue · black or blue on white.

## 6. Typography
- Everything around the logo is set in **Mona Sans** (variable, OFL licence), the same as the website.
- The wordmark is **not a font**. The letters are built from circles and stems. Never retype `arteo` in a font.

## 7. Don'ts
Don't stretch, slant or rotate · don't recolour outside the palette · don't swap the inks (blue a, pink r arch) · don't add shadows, outlines, gradients or glow · don't separate the "a" and "r" · don't place it on busy photos without a calm area · don't recreate the wordmark by typing it.
